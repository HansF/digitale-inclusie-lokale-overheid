# Stakeholder- en netwerkanalyse — werksjabloon

Dit sjabloon helpt je om de actoren rond digitale inclusie in kaart te brengen, hun rol en invloed te bepalen, en een gerichte samenwerkingsstrategie te kiezen.

**Gebruik:** start alleen of met een klein kernteam, en vul aan met partners. Een netwerkanalyse is nooit af.

---

## 1. Doel van de analyse

Beantwoord eerst:

- Waarvoor hebben we het netwerk nodig?
- Welke beslissing willen we nemen?
- Wie moet daarvoor mee?
- Wat is de scope (gemeente, regio, doelgroep)?

## 3. Analyse per actor

Vul voor de belangrijkste actoren (max. 15) deze tabel in.

| Actor | Belang (1-5) | Invloed (1-5) | Houding (-2 tot +2) | Relatie | Rol die we vragen |
| :--- | :---: | :---: | :---: | :--- | :--- |
| | | | | ☐ Sterk ☐ Zwak ☐ Geen | ☐ Uitvoerder ☐ Toeleider ☐ Locatie ☐ Expert ☐ Financier ☐ Ambassadeur ☐ Kritische vriend |
| | | | | ☐ Sterk ☐ Zwak ☐ Geen | |
| | | | | ☐ Sterk ☐ Zwak ☐ Geen | |

**Legenda:**

- **Belang:** hoeveel heeft de actor erbij te winnen of te verliezen?
- **Invloed:** hoeveel kan de actor de uitkomst beïnvloeden?
- **Houding:** -2 = tegen, 0 = neutraal, +2 = sterk voor.

## 5. Netwerkkaart

Teken een netwerkkaart. Gebruik:

- **cirkels** voor actoren;
- **lijndikte** voor sterkte van de relatie;
- **pijlen** voor richting van de samenwerking;
- **kleuren** voor type actor (intern, extern, overheid, middenveld).

**Vragen na het tekenen:**

- Wie is geïsoleerd?
- Wie heeft veel verbindingen (hub)?
- Waar zitten breuklijnen?
- Wie ontbreekt?
