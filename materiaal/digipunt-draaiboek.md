# Digipunt-draaiboek — van idee tot werking

Dit draaiboek begeleidt je stap voor stap bij het opzetten van een digipunt. Het is opgebouwd in vier fasen en bevat per fase de beslissingen, documenten en afspraken die je nodig hebt.

**Gebruik:** werk de fases in volgorde af, maar sla niets over. Een fase mag kort duren, maar niet verdwijnen.

---

## Fase 2 — Piloot (3 maanden)

### 2.1 Starten

- [ ] Team is opgeleid.
- [ ] Ruimte is ingericht.
- [ ] Registratiesysteem is klaar.
- [ ] Communicatie is gelanceerd.
- [ ] Partners zijn geïnformeerd.
- [ ] Noodprocedure is bekend.

---

### 2.2 Registreren

Registreer **eenvoudig** en **privacyvriendelijk**:

| Veld | Invulling |
| :--- | :--- |
| Datum | |
| Type vraag | ☐ Toestel ☐ Account ☐ Formulier ☐ itsme ☐ Veiligheid ☐ Anders |
| Nieuwe bezoeker? | ☐ Ja ☐ Nee |
| Doorverwezen? | ☐ Nee ☐ Ja, naar: |
| Postcode / wijk (optioneel) | |

**Niet registreren:** naam, inhoud van de vraag, wachtwoorden, persoonsgegevens.

---

### 2.3 Observeren

Noteer wekelijks:

- Welke vragen komen terug?
- Waar lopen bezoekers vast?
- Wat werkt niet?
- Wat missen we?
- Wat zeggen bezoekers?

---

### 2.4 Bevragen

**Bezoekers (3 vragen):**

1. Hoe heb je ons gevonden?
2. Wat kwam je doen, en is het gelukt?
3. Wat kunnen we beter doen?

**Digihelpers (3 vragen):**

1. Wat gaat goed?
2. Waar loop je vast?
3. Wat heb je nodig?
