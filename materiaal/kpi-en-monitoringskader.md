# KPI- en monitoringskader — sjabloon

Dit sjabloon helpt je een **eenvoudig, bruikbaar monitoringssysteem** op te zetten voor digitale inclusie. Het vertrekt van je doelen, kiest een minimale set indicatoren en legt vast wie wat meet.

---

## 1. Uitgangspunten

1. **Minder is meer.** Een tiental indicatoren is genoeg.
2. **Output én outcome.** Wat je doet, en wat het oplevert.
3. **Privacy by design.** Dataminimalisatie, anonimiteit, bewaartermijn.
4. **Meetbaar met redelijke inspanning.** Geen dure bevraging als een eenvoudige registratie volstaat.
5. **Gebruik de data.** Een indicator die niemand bekijkt, is ballast.

## 4. Definities

Leg vast wat je precies meet. Zonder definitie is een cijfer niet vergelijkbaar.

| Indicator | Definitie | Inclusie | Exclusie |
| :--- | :--- | :--- | :--- |
| Unieke bezoeker | | | |
| Nieuwe bezoeker | | | |
| Prioritaire groep | | | |
| Doorverwijzing | | | |
| Actieve helper | | | |

**Voorbeeld:**

> **Unieke bezoeker:** een persoon die in de meetperiode minstens één keer een individueel hulpmoment heeft gehad. Iemand die twee keer komt, telt één keer. Personen die alleen een toestel lenen, tellen niet mee.

---

## 5. Meetmethoden

| Methode | Waarvoor | Voor- en nadelen |
| :--- | :--- | :--- |
| **Registratie** | Bereik, vragen, doorverwijzingen | Eenvoudig, maar vraagt discipline |
| **Korte bevraging** | Tevredenheid, ervaring | Snel, maar lage respons |
| **Nameting** | Leereffect | Sterker bewijs, maar meer werk |
| **Interview** | Diepgang, verhalen | Rijk, maar niet representatief |
| **Observatie** | Gedrag, drempels | Direct, maar subjectief |
| **Web analytics** | Gebruik website | Objectief, maar zegt niets over begrip |
| **Bestaande data** | Context | Goedkoop, maar niet altijd actueel |

## 6. Registratieformulier

Houd het eenvoudig.

| Veld | Type | Verplicht? | Opmerking |
| :--- | :--- | :---: | :--- |
| Datum | Datum | Ja | |
| Type vraag | Keuze | Ja | Vaste categorieën |
| Nieuwe bezoeker | Ja/nee | Ja | |
| Doorverwezen | Ja/nee | Ja | |
| Bestemming | Keuze | Nee | Alleen bij ja |
| Postcode / wijk | Tekst | Nee | Optioneel, geanonimiseerd |
| Duur | Keuze | Nee | Kort / middel / lang |

**Niet registreren:**

- naam;
- adres;
- telefoonnummer;
- e-mailadres;
- inhoud van de vraag;
- wachtwoorden;
- geboortedatum.

## 8. Rapportage

### 8.1 Maandelijks (operationeel)

- Cijfers voor het team.
- Wat valt op?
- Wat passen we aan?

### 8.2 Per kwartaal (stuurgroep)

- Voortgang op de indicatoren.
- Wat werkt, wat niet?
- Welke beslissing is nodig?

### 8.3 Jaarlijks (college en raad)

- Overzicht van het jaar.
- Vergelijking met de nulmeting.
- Verhalen en quotes.
- Bijsturing van het actieplan.
- Budget en beslissingsvraag.

---

## 9. Data-ethiek

- [ ] We vragen alleen wat we nodig hebben.
- [ ] We leggen uit waarvoor we data gebruiken.
- [ ] We bewaren data niet langer dan nodig.
- [ ] We anonimiseren waar mogelijk.
- [ ] We delen geen individuele data.
- [ ] We rapporteren over groepen, niet over personen.
- [ ] We laten de DPO meekijken.
- [ ] We koppelen resultaten terug aan deelnemers.

---

## 10. Kwaliteitscheck

- [ ] Elke indicator heeft een definitie.
- [ ] Elke indicator heeft een baseline.
- [ ] Elke indicator heeft een streefwaarde.
- [ ] Elke indicator heeft een verantwoordelijke.
- [ ] De registratie is eenvoudig en privacyvriendelijk.
- [ ] Er is een dashboard.
- [ ] Er is een rapportagecyclus.
- [ ] De data worden gebruikt om bij te sturen.
- [ ] De DPO is betrokken.
- [ ] De doelgroep is betrokken bij de interpretatie.
