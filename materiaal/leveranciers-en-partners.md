# Leveranciers en partners — overzicht en afsprakenkader

Dit document helpt je om **leveranciers en partners** te kiezen, te beoordelen en afspraken vast te leggen. Het bevat:

1. een overzicht van het ecosysteem;
2. een beoordelingskader voor leveranciers;
3. een checklist voor samenwerkingsovereenkomsten;
4. een lijst van vragen voor elk type partner.

## Deel B — Beoordelingskader voor leveranciers

### 1. Functioneel

- [ ] Voldoet het product aan de behoefte?
- [ ] Is het gebruiksvriendelijk?
- [ ] Werkt het op de toestellen die de doelgroep gebruikt?
- [ ] Is het schaalbaar?
- [ ] Is het onderhoudbaar?

### 2. Toegankelijkheid

- [ ] Voldoet het aan **WCAG 2.2 AA**?
- [ ] Is er een **toegankelijkheidsverklaring**?
- [ ] Is er een **auditrapport**?
- [ ] Werkt het met **schermlezers**?
- [ ] Werkt het met **toetsenbord**?
- [ ] Werkt het bij **200% zoom**?
- [ ] Is er een **hersteltermijn** bij gebreken?

### 3. Privacy en veiligheid

- [ ] Is er een **verwerkersovereenkomst**?
- [ ] Wordt data **in de EU** bewaard?
- [ ] Is er **dataminimalisatie**?
- [ ] Is er **versleuteling**?
- [ ] Is er een **bewaartermijn**?
- [ ] Is er een **incidentprocedure**?
- [ ] Is er een **DPO** of privacycontact?

### 4. Kost

- [ ] Is de **aankoopprijs** duidelijk?
- [ ] Zijn de **licenties** duidelijk?
- [ ] Zijn de **onderhoudskosten** duidelijk?
- [ ] Zijn de **opleidingskosten** duidelijk?
- [ ] Zijn er **verborgen kosten**?
- [ ] Is er een **exitkost**?

### 5. Leverancier

- [ ] Is de leverancier **betrouwbaar**?
- [ ] Heeft de leverancier **referenties**?
- [ ] Is er **support** in het Nederlands?
- [ ] Is er een **aanspreekpunt**?
- [ ] Is er **continuïteit** als de leverancier stopt?
- [ ] Is er **data-export** mogelijk?

### 6. Duurzaamheid

- [ ] Is het product **reparerbaar**?
- [ ] Zijn er **reserveonderdelen**?
- [ ] Is er een **terugname** of **recyclage**?
- [ ] Is de **levensduur** realistisch?
- [ ] Is **refurbishment** mogelijk?

## Deel D — Vragen per type partner

### 1. Overheid

- Wat is het kader?
- Welke subsidies zijn beschikbaar?
- Wat zijn de voorwaarden?
- Wie is het aanspreekpunt?
- Wat is de timing?

### 2. Kenniscentrum

- Welke tools zijn beschikbaar?
- Welke materialen?
- Is er begeleiding?
- Wat zijn de kosten?
- Hoe blijven we op de hoogte?

### 3. Vormingspartner

- Welk aanbod?
- Voor wie?
- Waar?
- Wanneer?
- Kost?
- Toegankelijkheid?
- Doorverwijzing?

### 4. Welzijnspartner

- Wie bereikt de partner?
- Hoe verwijst de partner door?
- Wat zijn de grenzen?
- Is er een afsprakenkader?
- Is er een gedeelde registratie?

### 5. Technologieleverancier

- Voldoet het aan WCAG?
- Is er een audit?
- Wat is de kost?
- Wat is de support?
- Wat is de exit?
- Is er een verwerkersovereenkomst?

### 6. Doelgroeporganisatie

- Wie bereikt de organisatie?
- Wat is de vertrouwensrelatie?
- Wat heeft de organisatie nodig?
- Wat kan de organisatie bieden?
- Is er een wederkerige afspraak?
